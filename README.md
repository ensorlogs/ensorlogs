### 🛠️ Core Tech Stack

* **Frontend:** **Next.js 16** (App Router, Turbopack) + **TypeScript**
* **Estilos:** **Tailwind CSS 4** (Modo oscuro con acento ámbar neón)
* **Internacionalización:** `next-intl` (Soporte bilingüe: `/` ES + `/en`)
* **Backend & Base de Datos:** **Supabase** (Postgres unificado: texto + video, Storage para `stories-media`, Auth para `/admin`)
* **Comunicaciones:** **Brevo** (Formulario de contacto, email transaccional y captura de leads)
* **Infraestructura:** Despliegue continuo en **Vercel** bajo el dominio `ensorlogs.com`
